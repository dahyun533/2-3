# 2-3(mission7) 테스트하며 고치고 사용자 피드백 반영하기

코디세이 AI 네이티브 입학연수과정 미션7 제출물.

- **미션:** PC와 휴대폰에서 테스트하며 고치고, 사용자 피드백을 반영한 뒤 기획서를 최종 HTML에 맞게 수정함.
- **한 것:** 사용자 피드백으로 휴대폰에서도 최적화되어 작동이 되는 것을 목표로 추가기능을 넣고자 함. 휴대폰 탭 안내, 터치 조작, 기기 비율에 맞춘 이미지 저장 등 18번 더 수정(총 54번). 피드백으로 나무를 누르면 잎이 떨어지고 다람쥐가 나오는 이스터에그 추가.
- **결과:** PC·휴대폰 모두 겹침·잘림·저장 문제 없이 끝까지 진행되는 v3 완성. 기획서도 v3에 맞게 완료 기준과 추가 기능을 고침.
- **완성본:** `html/단풍나무(v3_Claude).html`

## 파일 목록

- `html/단풍나무(v3_Claude).html`
- `md/기획서(v3).md`
- `md/제작검증기록(v3).md`
- `결과 모음/v3_기능검증모음_42건.png`
- `결과 모음/v3_수정기록모음_54건.png`

## 파일 이름 규칙

- 폴더 안은 `html/`(페이지), `md/`(기획서·기록), `대화 캡처/`(AI와 나눈 주요 대화)로 나눔.
- 대화 캡처는 `AI이름_대화캡처번호.png`로 저장. 예: `claude_대화캡처1.png`, `chatgpt_대화캡처1.png`.
- 괄호 안은 내가 구분하려고 붙인 버전. 예: `기획서(v2).md` = 두 번째 기획서.
